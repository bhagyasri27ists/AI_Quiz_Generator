# 🧠 AI Quiz Generator

## 📌 Project Overview

AI Quiz Generator is a Python-based web application that extracts text from PDF files and automatically generates multiple-choice quiz questions.

## 🚀 Features

- 📄 Upload PDF files
- 📚 Extract text using PyPDF2
- 📝 Generate quiz questions
- ✅ Multiple-choice questions
- 🏆 Automatic score calculation
- 🌐 Interactive Streamlit interface
- 🤖 Google Gemini AI integration (with offline fallback)

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF2
- Google Gemini AI

## 📂 Project Structure

```text
AI_Quiz_Generator/
│── app.py
│── ai_quiz.py
│── pdf_reader.py
│── quiz_generator.py
│── requirements.txt
```

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
